sanecast

Projeção de volume de transações com limpeza automática do histórico. Projeto de demonstração, criado como referência e inspiração.

Abrir o painel de exemplo
O painel usa dados simulados. Ele é um arquivo único, sem servidor, gerado pelo comando uv run cli.py demo.

Documentação

  • README: visão geral, pré-requisitos e início rápido.
  • Método: limpeza, perfil do dia, ajuste ao vivo e faixa de incerteza.
  • Dados: formato de entrada, histórico mínimo e simulador.
  • Resultados: erro, cobertura da faixa e limites.
  • Arquitetura: da demonstração à produção.

Código

  • github.com/johnnytardin/sanecast (licença MIT)
  • Issues: relate casos em que a limpeza errou.
O sanecast é uma demonstração e não uma solução pronta para produção.
